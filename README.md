Jeevan Gyaan is a web-based societal awareness and life-skills learning platform designed specifically for higher school students in the Indian context And for Indian citizens.
The primary objective of the system is to bridge the gap between traditional textbook-based education and real-world societal knowledge.
It focuses on educating students about essential aspects of daily life, including civic responsibilities, awareness of important documents such as Aadhaar, digital safety, ethical behaviour, and basic legal knowledge, etc...
The platform offers structured and interactive learning modules supported by real-life scenarios, quizzes, and performance tracking features.
These components help students understand practical situations and enhance their decision-making abilities.
Additionally, the system incorporates a artificial intelligence components to provide personalized learning recommendations and an interactive assistant for resolving student queries,Module story generation , Scenario Simulator.
This makes the learning experience more adaptive, engaging, and student-centric. 
By combining educational content with practical insights, Jeevan Gyaan aims to nurture responsible behaviour and awareness among students.
The platform ultimately prepares learners to become informed, ethical, and socially responsible citizens who can actively contribute to society.

Application is developed by these :

1. Frontend:	React, Bootstrap, CSS	- Used to design and develop a responsive and interactive user interface for the platform.
2. Backend: 	Node.js, Express.js - Handles server-side logic, API creation, and communication between frontend and database.
3. Database:	MongoDB - Stores user data, learning modules, categories, and system information efficiently.
4. AI Implementation:  FastAPI - Used to integrate machine learning models and handle AI-based processing efficiently.
5. AI Model:	Qwen2.5 (Transformer Model) - Used for generating educational stories and providing intelligent chat responses.
6. Local AI Engine:	Ollama - Executes AI models locally, ensuring privacy, low latency, and better performance.
